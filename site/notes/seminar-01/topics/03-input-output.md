# Ввод и вывод

`printf` записывает текст в stdout, а `scanf` читает данные из stdin. Для ошибок предусмотрен отдельный поток stderr.

## Чтение чисел

Откройте **«Ввод программы»**, впишите `12 30` и запустите пример. Здесь ввод задаётся заранее; интерактивного терминала нет.

```c id=scanf-sum
#include <stdio.h>

int main(void) {
    int a, b;
    if (scanf("%d %d", &a, &b) != 2) {
        fprintf(stderr, "Ожидались два целых числа\n");
        return 1;
    }
    printf("Сумма: %d\n", a + b);
    return 0;
}
```

`&a` означает адрес переменной: `scanf` должен знать, куда записать результат. Подробнее об этом в [[seminar-03/topics/01-pointers|теме про указатели]].

## Ошибки и код завершения

```c id=stderr
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    printf("Начало программы\n");
    fprintf(stderr, "Пример диагностического сообщения\n");
    return 7;
}
```

Выводы разделены по вкладкам **stdout** и **stderr**. Код завершения `7` можно увидеть под редактором.

## Ошибка компиляции

В примере намеренно пропущена точка с запятой. Запустите его, откройте вкладку «Компилятор», затем исправьте ошибку.

```c id=syntax-error
#include <stdio.h>

int main(void) {
    printf("Найдите ошибку\n")
    return 0;
}
```
