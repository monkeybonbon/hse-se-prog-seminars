# Привет, C!

Программа начинается с маленького эксперимента. Напишем первую строчку, разберём её устройство и посмотрим, что произойдёт, если что-нибудь изменить.

> [!NOTE]
> Это живой конспект. Каждый пример на C можно редактировать и запускать прямо здесь. Ваши изменения сохраняются только в этом браузере.

## Первая программа

Знакомство с новым языком традиционно начинается с приветствия. Нажмите **«Запустить»**, чтобы скомпилировать код и увидеть результат.

```c id=hello
#include <stdio.h>

int main(void) {
    printf("Привет, мир!\n");
    return 0;
}
```

Попробуйте заменить `мир` на своё имя и запустить программу ещё раз. Вы только что изменили свою первую программу на C.

## Как устроен этот код

Здесь всего несколько строк, но у каждой есть своя роль.

| Фрагмент | Что он делает |
| --- | --- |
| `#include <stdio.h>` | Подключает объявления функций ввода и вывода |
| `int main(void)` | Определяет точку входа в программу |
| `printf(...)` | Выводит текст в стандартный поток вывода |
| `\n` | Переводит курсор на следующую строку |
| `return 0;` | Завершает программу с кодом успеха |

Фигурные скобки `{ }` объединяют инструкции в блок. Большинство инструкций завершаются **точкой с запятой**.

### Что значит «скомпилировать»?

Исходный текст ещё не является исполняемой программой. Компилятор проверяет его и переводит в машинные инструкции; линкер связывает их с библиотекой.

![[путь программы.svg]]

На этом сайте Clang и линкер работают в браузере через WebAssembly. Код не отправляется на сервер. При первом запуске потребуется скачать toolchain, поэтому первый эксперимент займёт больше времени.

## Немного практики

1. Выведите своё имя и номер группы на разных строках.
2. Добавьте ещё один вызов `printf`.
3. Уберите точку с запятой после `printf` и прочитайте сообщение компилятора.
4. Нажмите **«Сбросить»**, чтобы вернуть актуальный пример из конспекта.

> [!TIP]
> Запускайте пример сочетанием Ctrl + Enter (на Mac — ⌘ + Enter). Если программа зациклится, её можно остановить кнопкой.
