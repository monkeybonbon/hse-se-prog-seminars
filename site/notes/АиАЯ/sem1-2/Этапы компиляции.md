# Препроцессинг

> `gcc -E main.c -o main.i`

Раскрывает макросы, подставляет заголовочные файлы, удаляет комментарии

# Компиляция

> `gcc -S main.c -o main.s`

Преобразует код C в команды ассемблера

# Ассемблирование

> `gcc -c main.c -o main.o`

Переводит ассемблерный код в машинный код

# Линковка

> `gcc main.o -o main`

Объединяет один или несколько объектных файлов и используемые библиотеки (например, libc) в единый исполняемый файл
