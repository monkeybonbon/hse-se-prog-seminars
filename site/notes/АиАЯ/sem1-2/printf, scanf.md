
`printf("...", ...)` Форматированный вывод
Получает форматную строку и объекты для вывода
Позволяет с помощью форматных строк выводить данные в консоль

`scanf("...", ...)` Форматированный ввод
Получает форматную строку и **адреса** объектов для записи
Позволяет вводить данные из консоли в программу
 
# Формат

> **Флаги**
> `#` Значение преобразуется в «альтернативную форму».
> `0` Значение добавляет нули.
> `-` Выравнивает результат преобразования по левой границе поля.
> `␣ (пробел)`. Устанавливает перед положительными числами (или пустой строкой) знак пробела для знаковых преобразований.
> `+` Знак + или - всегда помещается перед числом со знаком.

> **Ширина**
> Необязательная строка из десятичных цифр (с первой цифрой, отличной от нуля) определяет минимальную ширину поля. Если преобразованное значение имеет меньшее количество знаков, чем ширина поля, то оно слева дополняется пробелами (или справа, если указан флаг левого преобразования).

> **Точность**
> Необязательный параметр точности в виде знака точки. сопровождается необязательной строкой десятичных цифр. Это позволяет ограничивать количество выводимых символом для преобразований типов: d, i, o, u, x, X; показывать определенное количество цифр после десятичной точки для преобразований: a, A, e, E, f, F; показывать максимальное количество значащих цифр для преобразований g, G или максимальное количество символов для печати строк при преобразованиях s, S.

> Модификаторы длины
> `hh` — signed char или unsigned char,
> `h` — short int или unsigned short int,
> `l` — long int или unsigned long int или double,
> `ll`— long long int или unsigned long long int,
> `L`— long double.

> **Спецификатор преобразования**
> `d` — десятичное число со знаком;
> `i` — для printf аналогично d, для scanf число со знаком, десятичное, восьмеричное или шестнадцатеричное, в зависимости от префикса;
> `o` – восьмеричное число без знака,
> `u` – десятичное число без знака,
> `x`, `X` — шестнадцатеричное число без знака,
> `f` – число с плавающей точкой, обычный формат,
> `e` – число с плавающей точкой, научный формат,
> `g` – число с плавающей точкой, формат по выбору;
> `c` – символ (или последовательность символов, если указана длина);
> `s` – строка из непробельных символов;
> `%` – символ %.
