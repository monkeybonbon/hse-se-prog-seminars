> Именованные ячейки памяти

Формат:
`<type> <name>;`
`<type> <name> = <value>;`
где 
`<type>` - тип данных, который будет хранить переменная
`<name>` - имя переменное
`<value>` - значение переменной

Примеры:
```c
int a;
int b = 20;
double c = 12.5;
char d = 'x';
```

Переменные хранятся в памяти (стеке), занимают определенное количество байт.
