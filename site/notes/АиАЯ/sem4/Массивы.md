# Одномерные массивы
> Хранит элементы одного типа, имеет фиксированный размер, хранится в памяти последовательно.

`int a[5];` - объявление неинициализированного массива целых чисел размера 5

`int a[] = {1, 2, 3}` - объявление инициализированного массива размера 3. При наличии инициализатора размер можно опустить.

> Память для массивов, для которых заведомо известен размер, выделяется **на этапе компиляции**

> Переменная массива является **указателем** на его первый элемент

```c
#include <stdio.h>

int main(void) {
	int a[] = {1, 2, 3, 4, 5};
	printf("%p %d", a, *a);
	return 0;
}
```

Соответственно, чтобы пройтись по всем элементам массива можно использовать адресную арифметику

```c
#include <stdio.h>

int main(void) {
	int a[] = {1, 2, 3, 4, 5};
	for (int i = 0; i < 5; i++) {
		printf("%p ", a + i);
	}
	printf("\n");
	for (int i = 0; i < 5; i++) {
		printf("%d ", *(a + i));
	}
	return 0;
}
```

Можно не заморачиваться с адресной арифметикой и использовать упрощенную конструкцию для индексации по массиву
`a[i]` - эквивалентно `*(a + i)`, взять i-й (по индексу) элемент массива

```c
#include <stdio.h>

int main(void) {
	int a[] = {1, 2, 3, 4, 5};
	for (int i = 0; i < 5; i++) {
		printf("%p ", &(a[i]));
	}
	printf("\n");
	for (int i = 0; i < 5; i++) {
		printf("%d ", a[i]);
	}
	
	return 0;
}
```

# Двухмерные массивы

Массивы могут содержать в себе другие массивы. При этом каждый внутренний массив должен быть одного размера с остальными

```c
#include <stdio.h>
int main(void) {
	int a[5][6];
	
	for (int i = 0; i < 5; i++) {
		for (int j = 0; j < 6; j++) {
			printf("%p ", &(a[i][j]));
			a[i][j] = i * 6 + j;
		}
		printf("\n");
	}
	
	for (int i = 0; i < 5; i++) {
		for (int j = 0; j < 6; j++) {
			printf("%d\t", a[i][j]);
		}
		printf("\n");
	}
	return 0;
}
```

# VLA массивы

В стандарте C99 есть возможность задавать размер массива **во время исполнения программы**, а не на этапе компиляции

Такие массивы называются **Variable-Length Arrays (VLA)**

Это позволяет нам задавать меняющийся от запуска к запуску размер, например после ввода переменной размера через `scanf`

```c
int main(void) {
	int n;
	scanf("%d", &n);
	
	int a[n]; // память выделится ВО ВРЕМЯ ИСПОЛНЕНИЯ
	
	for(int i = 0; i < n; i++) {
		scanf("%d", &a[i]);
	}
	
	return 0;
}
```

**Риски:**
- Переполнение стека при очень большом N - программа упадет на этапе Runtime, а не компиляции. А если и не упадет, то вызовет UB, так как перезатрет соседние переменные
- Небезопасно - нет проверки выхода за пределы массива на этапе компиляции

```c
#include <stdio.h>
int main(void) {
	int n;
	scanf("%d", &n);
	
	int a[n];

    for (int i = -n; i < 2 * n; i++) {
        printf("a[%d] \t %x \t %d\n", i, &a[i], a[i]);
    }
	
	return 0;
}
```
