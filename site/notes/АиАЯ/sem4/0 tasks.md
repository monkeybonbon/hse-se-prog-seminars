# 1.3 (1 б)
Допишите программу:
На вход даны два числа a, b; Необходимо поменять их местами **в памяти**, используя **только указатели**
```c
#include <stdio.h>

int main(void) {
	int a, b;
	scanf("%d %d", &a, &b);
	
	int* a_ptr = &a;
	int* b_ptr = &b;
	
	// Ваш код. Использовать только a_ptr, b_ptr
	// (можно создавать другие переменные)
	
	printf("%d %d", a, b);
	return 0;
}
```
