# Адрес
Память компьютера последовательна, и у каждой ячейки есть свой номер - **адрес**

Минимально адресуемая единица памяти - **1 байт**

Каждая переменная занимает в памяти какое-то количество подряд идущих ячеек. Номер первой из них называется **адресом переменной**

`&a` - операция взятия адреса переменной 

Адрес существует только у объектов, которые хранятся в памяти. Нельзя взять адрес от выражения (например, `&(a+b)`, `&(&x)` - некорректно).

# Указатель

Адрес является числом и тоже может быть сохранен в переменную. Переменная, хранящая адрес называется **указателем**

`<type>*` - тип указателя на переменную типа type

```c
#include <stdio.h>

int main(void) {
	int b = 5;
	int c = 10;
	
	int* b_ptr = &b;
	int* c_ptr = &c;
	
	printf("%p %p", b_ptr, c_ptr);
	return 0;
}
```

Все указатели, независимо от типа данных переменной на которую они указывают, имеют один и тот же размер (определяется системой)

Чтобы из указателя получить значение переменной, на которую он указывает - необходимо применить операцию разыменования `*a_ptr`

```c
#include <stdio.h>

int main(void) {
	int b = 5;
	int c = 10;
	
	int* b_ptr = &b;
	int* c_ptr = &c;
	
	printf("%d %d", *b_ptr, *c_ptr);
	return 0;
}
```

`NULL` - специальный указатель, указывающий "никуда"
`int* a_ptr = NULL;`

Указатель хранится в памяти, следовательно, у него тоже есть адрес, следовательно, его тоже можно сохранить в указатель. Это будет **двойной указатель**

```c
int main(void) {
	int a = 2;
	int* a_ptr = &a;
	int** a_ptr_ptr = &a_ptr;
	int b = **a_ptr_ptr;
	return 0;
}
```

# Адресная арифметика

Так как адреса являются числами, с ними можно проводить арифметические манипуляции (сложение и вычитание)

- `type* ptr` + число = `type* ptr`
	- число - sizeof(`type`)
- `type* ptr` - число = `type* ptr`
	- число - sizeof(`type`)
- `type* ptr` - `type* ptr` = число
	- число - sizeof(`type`)

То есть числа в таких операциях **означают не количество байт**, а **количество элементов исходного типа данных**

```c
#include <stdio.h>

int main(void) {
	int b = 5;
	int c = 10;
	long long bl = 5;
	long long cl = 10;
	
	int* b_ptr = &b;
	int* c_ptr = &c;
	
	long long* bl_ptr = &bl;
	long long* cl_ptr = &cl;
	
	printf("%ld\n", b_ptr - c_ptr);
	printf("%ld\n", bl_ptr - cl_ptr);

	return 0;
}
```


```c
#include <stdio.h>

int main(void) {
	int b = 5;
	int c = 10;
	
	int* b_ptr = &b;
	int* c_ptr = &c;
	
	printf("%p %p \n", b_ptr, c_ptr);
	printf("%ld\n", b_ptr - c_ptr);
	printf("%p\n", c_ptr + 1);
	
	*(c_ptr + 1) = 20;
	printf("%d", b);
	return 0;
}
```
