## Битовые операции

`a & b` - побитовое И 
`a | b` - побитовое ИЛИ
`a ^ b` - побитовый XOR
`a << n` - сдвиг влево на n бит
`a >> n` - сдвиг вправо на n бит. *Освободившиеся старшие биты заполняются знаковым*

```c
#include <stdio.h>

int main(void) {
	short int a = 0xfa0f; // 1111 1010 0000 1111 
	short int b = 0xfb22; // 1111 1011 0010 0010
						
	printf("a & b:\t0x%04hx\n", a & b);   
	printf("a | b:\t0x%04hx\n", a | b);   
	printf("a ^ b:\t0x%04hx\n\n", a ^ b); 
	
	printf("a << 1:\t0x%04hx\n", a << 1); 
	printf("a << 3:\t0x%04hx\n", a << 3);
	printf("a >> 1:\t0x%04hx\n", a >> 1); 
	printf("a >> 4:\t0x%04hx\n", a >> 4); 
	return 0;
}
```

> При сдвиге вправо на освободившиеся места слева встает **знаковый бит**

## Арифметические операции
`a + b` - сложение
`a - b` - вычитание
`a * b` - умножение
`a / b` - деление 
`a % b` - остаток от деления *(только с целочисленными)*

При делении нацело результат округляется **в сторону нуля**
Таким образом, **знак остатка совпадает со знаком делимого**

```c
#include <stdio.h>

int main() {
	int a = 25;
	int b = 8;
	
	printf("%d / %d = %d (ост. %d)\n", a, b, a/b, a%b);
	printf("%d / %d = %d (ост. %d)\n", a, -b, a/(-b), a%(-b));
	printf("%d / %d = %d (ост. %d)\n", -a, b, (-a)/b, (-a)%b);
	printf("%d / %d = %d (ост. %d)\n", -a, -b, (-a)/(-b), (-a)%(-b));
	
	return 0;
}

```

## Логические операции
Результатом логических операций является 0 или 1 (ложь или правда)

`a == b` - равенство
`a >= b` - больше или равно
`a > b` - больше
`a <= b` - меньше или равно
`a < b` - меньше
`a != b` - не равно

`A && B` - выполняются оба простых логических выражения
`A || B` - выполняется хотя бы одно логическое выражение
`!A` - отрицание результата логического выражения

> Для операций `&&` `||` действует **правило короткой логики:**
> Сначала вычисляется значение первого аргумента. Если по его значению заведомо известен результат операции - второй аргумент не вычисляется

```c
#include <stdio.h>

int main() {
	int a = 0;
	int res = (2 < 0) && (a++);
	printf("%d %d\n", res, a);
	
	res = (2 > 0) || (a++);
	printf("%d %d\n", res, a);
	
	res = (2 < 0) || (a++);
	printf("%d %d\n", res, a);
	
	return 0;
}
```

## Тернарная операция условия
`A ? <1> : <2>` 
При выполнении условия А выполняется код 1
При невыполнении - код 2

```c
#include <stdio.h>

int main(void) {
	int a = 5;
	
	(a > 0) ? printf("больше 0\n") : printf("меньше 0\n");
	
	// Можно проще!
	
	printf((a > 0) ? "больше 0\n" : "меньше 0\n");
	
	return 0;
}
```

## Запятая
Последовательно вычисляет выражения слева направо, возвращает результат самого правого выражения.
