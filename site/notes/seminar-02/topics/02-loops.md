# Циклы

Когда нужно повторить действие, используйте `for` или `while`.

## Сумма от 1 до n

```c id=sum-loop
#include <stdio.h>

int main(void) {
    int n = 10;
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    printf("Сумма: %d\n", sum);
    return 0;
}
```

Проверьте результат формулой:

$$
1 + 2 + \dots + n = \frac{n(n+1)}{2}.
$$

## Бесконечный цикл

Этот пример намеренно не завершается. После запуска нажмите **«Остановить»** или дождитесь ограничения в 10 секунд. Интерфейс останется доступен, потому что C-программа выполняется в отдельном worker.

```c id=infinite-loop
int main(void) {
    volatile unsigned long counter = 0;
    for (;;) {
        counter++;
    }
}
```
