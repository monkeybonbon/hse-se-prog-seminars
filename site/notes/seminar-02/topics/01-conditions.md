# Условный оператор

Условие позволяет выбрать действие в зависимости от значения выражения. Ноль считается ложью, любое ненулевое значение — истиной.

## Ветвление if / else

```c id=condition
#include <stdio.h>

int main(void) {
    int n = -3;
    if (n > 0) {
        printf("Положительное\n");
    } else if (n < 0) {
        printf("Отрицательное\n");
    } else {
        printf("Ноль\n");
    }
    return 0;
}
```

## Логические операции

| Оператор | Значение |
| --- | --- |
| `&&` | И: оба условия истинны |
| `\|\|` | ИЛИ: хотя бы одно условие истинно |
| `!` | НЕ: инверсия условия |

Не путайте присваивание `=` со сравнением `==`.
