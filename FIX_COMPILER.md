# Исправления C-песочницы

- Исправлена обработка Emscripten `quit(status)` без объекта исключения: ранее попытка обратиться к `error.status`, когда `error` был `undefined`, приводила к вторичной ошибке.
- Worker теперь сообщает точную текущую стадию (скачивание, инициализация Clang, монтаж sysroot, компиляция, LLD, WASI), а UI её показывает.
- Ошибки дополнены указанием этапа и stack trace в диагностике.
- Отсутствие выходного файла после успешного кода возврата теперь даёт понятную ошибку.
- Добавлена обработка `messageerror` между worker и браузером.

## Проверка на своей машине

```powershell
cd site
npm ci
npm run toolchain
npm run dev
```

После запуска тестового примера `printf("Hello\\n")` стадия должна перейти в «Выполнение завершено · код 0». Если остановится на иной стадии, текст статуса теперь покажет, где именно. Проверяйте инструменты разработчика (F12, Console/Network).

**Внимание:** бинарники toolchain не находятся в исходном ZIP и в текущей среде недоступна загрузка из raw.githubusercontent.com, поэтому настоящий запуск WASM-компилятора здесь проверить не получилось. Это диагностическое и защитное исправление, а не подтверждённый end-to-end ремонт.
