### Эталон письменных задач

В задаче 1 **каждая строка рассматривается независимо из исходного состояния**. Последовательное выполнение строк меняет i/p и уже не отвечает исходной таблице.

| Выражение | Значение | Тип | Побочный эффект |
|---|---:|---|---|
| `i++` | 3 | int | i=4 |
| `++i` | 4 | int | i=4 |
| `a[i]--` | 4 | int | a[3]=3 |
| `*p++` | 2 | int | p=&a[2] |
| `++*p` | 3 | int | a[1]=3 |
| `*++p` | 3 | int | p=&a[2] |
| `p-a` | 1 | ptrdiff_t | нет |
| `&c[8]-q` | 8 | ptrdiff_t | нет |
| `a-q` | недопустимо | нет корректного типа | вычитание int* и char* недопустимо |

Задача 5: `size_t count = sizeof(a) / sizeof(a[0]);` — **10 элементов**. sizeof — оператор, не функция; формулировка из условий не использована как основание для снижения.

Использованы чтение исходников и проверки C11/Clang/WASM: задача 6 — 3 входа; задачи 7–10 — по 4; задача 11 — 7. Проверялись отрицательные числа, повторы, прямоугольные и вырожденные матрицы, положение ладьи у края. Дополнительно проверены требования отдельного массива в задаче 7 и поворота на месте в задаче 10. Успешный конечный набор тестов не является доказательством для всех входов. Технические замены числового scanf_s на scanf для другой платформы и добавление только печати в отдельных проверочных копиях отмечены в соответствующих задачах.
