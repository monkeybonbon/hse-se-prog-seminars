### Частичный зачёт

В условиях указаны максимумы задач. Приведённые здесь частичные баллы за правильность — **принятая при этой проверке методика**, а не дополнительная разбалловка из конспектов. Коэффициенты дедлайнов применены отдельно, ровно по условиям преподавателя.

- Задача 1: равные доли за 27 полей таблицы (9 строк × значение, тип, побочный эффект). Для недопустимого выражения достаточна явная отметка ошибки: численного значения и нормального типа у него нет. Полностью пропущенная строка — 0 за неё.
- Задача 2: по 1/6 за каждое выражение. Оба последовательных варианта размера указателей, 4 на 32-битной и 8 на 64-битной платформе, приняты. Проверочная среда WASM32 не определяет единственный допустимый ответ студента.

### Эталон письменных задач

В задаче 1 **каждая строка рассматривается независимо из исходного состояния**. Последовательное выполнение строк меняет i/p и уже не отвечает исходной таблице.

| Выражение | Значение | Тип | Побочный эффект |
|---|---:|---|---|
| `i++` | 3 | int | i=4 |
| `++i` | 4 | int | i=4 |
| `a[i]--` | 4 | int | a[3]=3 |
| `*p++` | 2 | int | p=&a[2] |
| `++*p` | 3 | int | a[1]=3 |
| `*++p` | 3 | int | p=&a[2] |
| `p-a` | 1 | ptrdiff_t | нет |
| `&c[8]-q` | 8 | ptrdiff_t | нет |
| `a-q` | недопустимо | нет корректного типа | вычитание int* и char* недопустимо |

Задача 2 на обычных платформах с четырёхбайтным int: **9, 20, sizeof(int*), sizeof(char*), 4, 1**. Указатели обычно оба по 8 байт на 64-битной платформе или оба по 4 на 32-битной. Абстрактный стандарт C не фиксирует int в 4 байта; ответы оценены в обычной для семинара модели с int=4.

Задача 3:

```c
for (int i = -5; i < 11; ++i)
    p[i] = 0;
```

Задача 4 в принятой в самом задании модели непрерывного размещения элементов: **19, 11, -8**.

Задача 5: `size_t count = sizeof(a) / sizeof(a[0]);` — **10 элементов**. sizeof — оператор, не функция; формулировка из условий не использована как основание для снижения.
