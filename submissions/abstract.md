# 03.11.2026

## Вывод через printf

```c
printf("%d\n", 5);       // целое число → 5
printf("%.3f\n", 12.5);  // дробное число, 3 знака после точки → 12.500
```

| спецификатор | тип |
|---|---|
| `%d` | `int` |
| `%ld` | `long int` |
| `%lld` | `long long int` |
| `%u` | `unsigned int` |
| `%f` | `float` / `double` (в `printf`) |
| `%lf` | `double` (в `scanf` — обязательно `%lf`!) |
| `%c` | `char` (как символ) |

## Типы данных

| тип | что хранит | размер | диапазон / заметки |
|---|---|---|---|
| `char` | символ (число) | 1 байт | от −128 до 127, код по таблице ASCII |
| `short int` | целое число | 2 байта | от −2¹⁵ до 2¹⁵ − 1 |
| `int` | целое число | 4 байта | от −2³¹ до 2³¹ − 1 (≈ ±2·10⁹) |
| `unsigned int` | целое без знака | 4 байта | от 0 до 2³² − 1 |
| `long long int` | целое число | 8 байт | от −2⁶³ до 2⁶³ − 1 (≈ ±9·10¹⁸) |
| `float` | вещественное число | 4 байта | почти не используется (мало точности) |
| `double` | вещественное число | 8 байт | обычно берут его |

## Инкремент: x++ и ++x

| запись | что делает |
|---|---|
| `x++` | сначала возвращает `x`, потом прибавляет 1 |
| `++x` | сначала прибавляет 1, потом возвращает `x` |

```c
int x = 5;
int a = x++;  // a = 5, x = 6
int b = ++x;  // b = 7, x = 7
```

## Деление и типы

| `a` | `b` | `a / b` |
|---|---|---|
| `int` | `int` | `int` (дробная часть отбрасывается: `7 / 2 = 3`) |
| `double` | `double` | `double` (`7.0 / 2.0 = 3.5`) |
| `int` | `double` | `double` (`7 / 2.0 = 3.5`) |

`%` — остаток от деления (только для целых): `7 % 2 = 1`.

## Ввод через scanf

```c
int x, y;
scanf("%d %d", &x, &y);   // & — передаём адрес переменной
printf("%d %d\n", x, y);

char a;
scanf("%c", &a);
printf("%d\n", a);        // выведет код символа
```

## Безопасный ввод

`scanf` возвращает, сколько значений удалось прочитать — если не столько, сколько ждали, выходим.

```c
int x, y;
if (scanf("%d %d", &x, &y) != 2) {
    return 1;
}
printf("%d %d\n", x, y);
```

## char

`char` — это число, просто его можно показать как символ.

```c
char a = 'a';
printf("%d\n", a);  // 97 (код 'a' в ASCII)
printf("%c\n", a);  // a

printf("%c", 1 + '0');  // '1' — так цифру превращают в символ
```

## Префиксы (система счисления)

| префикс | система | пример |
|---|---|---|
| `0b...` | 2-я | `0b101` = 5 |
| `0...` | 8-я | `015` = 13 |
| `0x...` | 16-я | `0x1F` = 31 |

> ⚠️ `015` — это **не** 15, а 13: ведущий ноль означает восьмеричную запись.

## Суффиксы (тип числа)

| суффикс | тип |
|---|---|
| `l`, `L` | `long int` |
| `ll`, `LL` | `long long int` |
| `u`, `U` | `unsigned` |

```c
printf("%ld\n", 5l);    // для long — %ld
printf("%lld\n", 5ll);  // для long long — %lld
printf("%u\n", 5u);     // для unsigned — %u
```

## Приведение типов

`(тип)значение` — временно превращает значение в другой тип.

```c
int a = 7, b = 2;
printf("%d\n", a / b);           // 3
printf("%f\n", (double)a / b);   // 3.500000
```

### Переполнение

Тип результата выбирается **до** присваивания:

```c
long long mult(int a, int b) {
    return a * b;               // ❌ умножение в int → переполнится, потом уже в long long
}

long long mult(int a, int b) {
    return (long long)a * b;    // ✅ считаем сразу в long long
}
```

## Логические операторы и сравнения

| оператор | смысл |
|---|---|
| `==`, `!=` | равно, не равно |
| `<`, `>`, `<=`, `>=` | сравнения |
| `&&` | И (оба условия верны) |
| `\|\|` | ИЛИ (хотя бы одно верно) |
| `!` | НЕ |

Результат сравнения — число: `1` (правда) или `0` (ложь).

```c
printf("%d\n", x >= -5 && x <= 19);  // 1, если x в [-5; 19]
printf("%d\n", x <= 8 || x > 12);    // 1, если x не в (8; 12]
```

## Тернарный оператор

`условие ? если_да : если_нет`

```c
(a > 0) ? printf(">0") : printf("<=0");

// или короче — тернарный оператор возвращает значение:
printf((a > 0) ? ">0" : "<=0");

int m = (a >= b) ? a : b;   // максимум из двух
```

## if / else

```c
if (a > 0) {
    printf("положительное");
} else if (a == 0) {
    printf("ноль");
} else {
    printf("отрицательное");
}
```

Если внутри **одно** действие, скобки можно не ставить:

```c
if (a > 0) a = a + 1;
```

> ⚠️ Без скобок к `if` относится **только первая** строка, даже если вторая с отступом:
> ```c
> if (a[i] == x)
>     printf("%d", i);
>     f = 1;           // выполнится ВСЕГДА, отступ ничего не значит
> ```

## Циклы

```c
for (int i = 0; i < n; i++) {   // начало; условие; шаг
    // повторится n раз
}

while (x != 0) {                 // сначала проверка, потом тело
    // ...
}

do {                             // сначала тело, потом проверка —
    scanf("%d", &x);             // выполнится хотя бы 1 раз
} while (x != 0);
```

## Указатели

| запись | смысл |
|---|---|
| `int* p` | указатель на `int` (хранит адрес переменной типа `int`) |
| `&a` | адрес переменной `a` |
| `*p` | разыменование: значение по адресу `p` |
| `NULL` | специальный указатель «в никуда» |

```c
int a = 5;
int* p = &a;   // p хранит адрес a
*p = 10;       // меняем a через указатель → a = 10
```

### Адресная арифметика

`p + 1` сдвигает адрес не на 1 байт, а на **размер типа**: на 4 байта для `int`, на 8 для `long long`.

```
байты:   1  2  3  4  5  6  7  8
        [    a     ][    b     ]
         ^           ^
       a_ptr       b_ptr
```

- адреса отличаются на 4 байта;
- `b_ptr - a_ptr = 1` — разность указателей считается **в элементах** (1 `int`), а не в байтах.

## Массивы

### Одномерные

```c
int a[5];            // массив из 5 int: a[0] … a[4]
int b[] = {1, 2, 3}; // размер посчитается сам (3)
```

Имя массива — это указатель на его первый элемент:

```c
a[i] == *(a + i)     // i-тый элемент
```

> ⚠️ Индексы с `0` до `n - 1`. `a[n]` — уже за пределами массива.

Ввод и вывод массива:

```c
int n;
int a[100];
scanf("%d", &n);
for (int i = 0; i < n; i++) {
    scanf("%d", &a[i]);
}
for (int i = 0; i < n; i++) {
    printf("%d ", a[i]);
}
```

### Двумерные

```c
int a[5][6];                     // 5 строк, 6 столбцов
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 6; j++) {
        printf("%d ", a[i][j]);
    }
    printf("\n");
}
```

### VLA (массивы переменной длины)

```c
int n;
scanf("%d", &n);
int a[n];   // размер известен только во время выполнения
```

Память под такой массив выделяется на стеке во время работы программы — при большом `n` программа может упасть, поэтому VLA лучше не использовать.
