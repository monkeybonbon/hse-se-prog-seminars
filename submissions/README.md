# Решения студентов

Не добавляйте решения в main. Создайте свою ветку `BPI2412_Ivanov` (номер группы и фамилию замените своими).

Решения: `submissions/seminar-01/1.c`, `submissions/seminar-01/2.c` и т. д. Каждый файл — самостоятельная программа C.

Все пути указаны от корня репозитория. Папка `site/` содержит сайт и конспекты; для сдачи заданий её менять не нужно. Команды Git приведены в [основной инструкции](../README.md).

Сдача фиксируется push вашей ветки; Pull Request и merge не требуются. Для создания ветки необходимо право записи в репозиторий — его выдаёт преподаватель.

Формат имени: `^BPI[0-9]+_[A-Za-z]+$`. Сборщик читает только пути файлов и не компилирует решения. «Загружено» означает наличие файла, а не результат проверки.
