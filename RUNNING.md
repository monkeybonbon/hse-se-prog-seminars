# Запуск заданий в CLion

Открой корень проекта `hse-se-prog-seminars` как CMake-проект.
Если CLion предложит загрузить `CMakeLists.txt`, нажми **Load CMake Project**.

1. Выбери задание в списке конфигураций сверху, например `seminar-05_1`.
2. Нажми зелёную кнопку **Run**. CLion сначала скомпилирует файл, затем запустит.
3. Вывод программы и ввод для `scanf` доступны в окне **Run**.

Также можно запускать задание зелёным треугольником рядом с `main`.

Каждый `.c` или `.cpp` в `submissions/` собирается отдельно: несколько функций
`main` в разных заданиях не конфликтуют. Для нового задания создай файл,
например `submissions/seminar-05/3.c`, и выполни **Tools → CMake → Reload CMake Project**.
Появится цель `seminar-05_3`.

Файлы `.c` используют C17, `.cpp` — C++20. Для `printf` и `scanf` в C
подключай `#include <stdio.h>`.
